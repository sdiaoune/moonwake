# Moonwake: The Long Dawn — implementation contract

Player feedback: the original twelve-stage game clears in about ten minutes. The expansion targets a 60–90 minute first journey through substantially more authored content and stronger challenge progression. Experienced clears will remain faster; there is no waiting, movement slowdown, mandatory grinding, or collectible gate.

The player's explicit priority is more exploration. Every new room must offer at least two substantial alternative routes where feasible: several platforms across real screen space, tucked-away alcoves, a returning roof pocket or lower passage, star/lantern clues, and useful rejoin points. Preserve a fluid, forgiving main path. Later worlds teach a few distinctive spring arcs, moving rides, and lantern transfers with catch surfaces; tight jumps are not the main source of length. Original first rooms remain recognizable.

## Campaign

- 24 stages, eight worlds, three continuous rooms per stage: 72 authored rooms.
- Three optional seals per room, nine per stage, 216 overall. Rank S requires nine on the current run within the full-stage par; collection never gates the ending.
- Optional S pars have a content-validation lower bound of 75 seconds. Current authored pars are 95–120 seconds, derived from independently observed all-nine clear ticks ×1.45, rounded up to five seconds; they tune learned-route replay and do not measure first-player duration.
- Room coordinates stay below 1920 pixels for the native signed fixed-point engine. Target room length 1536–1856 pixels, with varied traversal phrases and generous recoverable rest areas.
- One checkpoint inside every room; advancing also establishes a new room checkpoint. Room transitions keep the stage clock, stars, and current-run seals. No intermediate clear menu. Continue can resume the selected room.
- Worlds 0–3 retain Saffron Harbor, Jade Monsoon, Violet Engines, Moonwhale. Worlds 4–7: Ember Festival, Pearl Observatory, Aurora Orchard, Dawn Archive.
- Boss type 1: Rainbell Warden, world 1 finale; 2: Comet Manta, world 3 finale; 3: Prism Sentinel, world 5 finale; 4: Dreamwhale, world 7 finale. Only final room of each world finale contains its boss.
- Preserve original levels as first rooms of stages 0–11, with appropriate tuning. The original final Dreamwhale is replaced by the midgame Manta. New rooms must have independent encounter/route compositions, not merely copies with longer gaps.

## Native interfaces and file ownership

Level specialist owns `src/levels.h`, `src/levels.c`, `src/campaign_0.c` … `src/campaign_7.c`, `tools/build_campaign.py`, `tools/check_campaign.py`, `docs/routes.json`, and `docs/design.md`. Keep existing struct fields; append `uint8_t mechanic` to LevelDef. Define LEVEL_COUNT 24, WORLD_COUNT 8, ROOMS_PER_STAGE 3. Existing limits remain 48 platforms, 64 pickups, 12 enemies. Add PLATFORM_MOVER 4 and ENEMY_JELLY 3. Mechanic 0 normal, 1 air wind to the right, 2 air wind to the left; use wind gently and signpost it through intro lines. Mover width 24–40 px; original x is the center of a +/-16 px horizontal oscillation. Place stable launch/catch surfaces nearby. Root implements movement/collision/drawing.

Keep `level_load(id, ...)` as room-zero wrapper. Add `level_load_room(id, room, ...) BANKED`. API dispatcher lives in bank 3; each `campaign_N.c` lives in bank 16+N and supplies BANKED `campaign_N_load(local_stage, room, ...)`, plus room-zero info, intro, par functions as needed. Never switch away from the bank executing C code: use banked calls and copy constant data to RAM before return. `level_info(id,...)` returns stage/room-zero info. `level_par(id)` returns full three-room seconds. Route schema: top-level `levels` contains 24 stages, each stage includes `rooms` with three complete current v1 route objects and `par_seconds`; keep room-zero fields on the outer stage for legacy consumers until root updates tests. Each room retains its own `main_route`, `seal_routes`, platform/pickup/enemy arrays, lesson and new movement/encounter annotation. Original three seals persist in first-room data.

Art specialist owns `tools/build_art.py`, `assets/`, `src/art.h`, `src/art_data.c`, `src/world_*.c`, `src/title_art.c`, and `docs/art.md`. Eight panorama banks 8–15, unchanged tile/palette allocations. Author original new four worlds and three additional boss tiles, preserve the original Dreamwhale as boss type 4. Export `const unsigned char boss_tiles[4][256]` in bank 1, boss order above. Export eight terrain sets (256 bytes each). Original shared sprite patterns 52/53 are assigned to an 8x16 moving-platform segment with visible cream top and solid dark underside; use palette 5. Jelly reuses owl shape only temporarily; author 8x16 jelly tiles 54/55 and animation 56/57 (palette 2). Root loads a selected boss into sprite tile slots 64–79 in ROM0. Preserve the original game title and all existing font glyphs. Keep distinct native scenery with readable quiet play space.

Audio specialist owns `src/music.c`, `src/music.h`, `tools/render_music.py`, `docs/audio/`, and `docs/soundtrack.md`. Existing scenes 0–7 retain their IDs. Add world scenes 8–11 for worlds 4–7, and boss scenes 12–14 for Warden/Manta/Sentinel; original scene 5 is Dreamwhale. Total 15 themes. Preserve lead continuity, eight SFX IDs, mute and CPU budget. Distinct themes, not transposed duplicates. Re-render production APU captures and verify all channel/clip/mute properties.

Root owns engine, save migration, menus/atlas, Makefile, controller playtests, integration, release packaging, and hardware installation. Runtime bank 4 may be split into an additional bank if necessary; 512 KiB ROM with 32 banks. The original public release and its ROM remain available.

Save v2 uses CRC-protected 192-byte slots at A200 and A300. A generation fence at A3F0–A3F3 is committed after the first valid v2 write, preventing legacy resurrection after newer slot headers are damaged. If both v2 slots and the fence are destroyed, the cartridge cannot distinguish this from a never-migrated save without modifying legacy bytes. Original MW v1 at A100/A180 and Signal Bloom slots remain untouched. Native per-stage seal_bits expands to uint16_t, best frames remains uint16_t, and current room/run counters persist. A committed stage-clear flag makes Continue advance after a clear while still allowing an active atlas replay to resume. V1 migration preserves unlocks/collected first-room seals, invalidates incompatible speed medals/times, unlocks the first new world for old completed saves, and clears expanded completion. New-game reset changes v2 data only.

## Quality gates

Static geometry/caps/signposting, native art exact-decode/VRAM/color checks, controller-only all-room reachability, fresh linear recording replay, checkpoint and cross-room seal retention, resume/migration/CRC recovery, atlas pages, mute, arena/frame cadence, and final ending. Independent play/visual critics review the expanded build and identify concrete defects without automatically awarding a desired score. 60–90 minutes remains a first-player design target, not a fabricated human test measurement.
